# Git HOL 5

## Objective

Clean repository and synchronize with remote repository.

---

## Verify Status

```bash
git status
```

---

## List Branches

```bash
git branch
```

---

## Pull Latest Changes

```bash
git pull origin main
```

---

## Push Local Changes

```bash
git push origin main
```

---

## Verify Remote Repository

Open GitHub repository and verify the latest changes are reflected.
